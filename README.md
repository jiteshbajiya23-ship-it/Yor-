# Xiao Bhai Donghua - File Store Bot

Telegram file sharing bot for [xiaobhaidonghua.com](https://xiaobhaidonghua.com) donghua episodes.
Built on the open-source Codeflix FileStore (GPL-3.0, see LICENSE).

Features: force-sub (request mode), shortener, premium users, auto-delete, batch/genlink, broadcast, ban/unban, multi DB channels.

Commands: /start, /genlink, /batch, /custom_batch, /shortner, /users, /broadcast, /settings
